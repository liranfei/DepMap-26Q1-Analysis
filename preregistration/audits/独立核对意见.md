## 一、必须改（不改则冻结后要么结果做不出来、要么决策规则失效）

### M-1　E2 的 Monte Carlo 判据按设计几乎必然失败（plan A §4 "Pre-specified expectations" E2）

- **问题**：E2 要求"在每一个 k = 1 的格子里，第一类错误的 95% Monte Carlo 上界 ≤ 0.06"，而每格只有 2,000 个基因。
- **理由**（已计算）：n = 2,000 时，Wilson 和 Clopper–Pearson 双侧 95% 上界 ≤ 0.06 都要求拒绝数 ≤ 99（观测率 ≤ 0.0495）。即使检验的真实水平**正好**是 0.05，单格通过概率也只有 P(Bin(2000, 0.05) ≤ 99) ≈ 0.49；真实水平 0.048 时约 0.65；0.045 时约 0.85。k = 1 的零假设格子至少有 4 个靶谱系 × 3 个 δ × 2 种噪声 = 24 格，要求"每一格"都过，那么一个完全校准的检验整体通过概率约为 0.49^24 ≈ 3×10⁻⁸（真实水平 0.048 时约 3×10⁻⁵，0.045 时约 0.02）。所以无论 M2、M3 好不好，E2 基本都会失败，决策规则会落到"Neither meets all three"。这正是"被设计本身人为触发失败"。
- **改法**（三选一，写死在计划里）：
  (a) 把零假设格子（β = 0）的重复数提高到每格 20,000 个基因：此时上界 ≤ 0.06 相当于观测率 ≤ 约 0.0567，真实水平 0.05 时单格通过概率 > 0.9999；
  (b) 保持 2,000，判据改为"点估计 ≤ 0.06，且 95% **下界** ≤ 0.05"（即没有证据表明超过名义水平太多）；
  (c) 判据改为"在所有格子合并的 Holm 校正下，没有一格显著 > 0.06"。
  推荐 (a)，计算量很小。同时写明区间类型（建议 Clopper–Pearson 双侧 95%）。E2r 也同样处理。

### M-2　效应网格相对真实噪声太大，E3 会"无格可评"，E1 是平凡成立（plan A §4 Design 与 E1/E3）

- **问题**：β ∈ {−0.25, −0.5, −1.0}、δ ∈ {−0.3, −0.6} 用的是绝对尺度，但 σ_g 取自真实的"每基因合并谱系内 SD"。
- **理由**（已计算，26Q1，1,192 个癌症模型，18,531 个基因）：合并谱系内 SD 的分位数为 5% 0.102、25% 0.118、**中位数 0.133**、75% 0.165、95% 0.334、99% 0.457；只有 0.6% 的基因 SD > 0.5。因此 β = −0.25 大约是 1.9 个 SD。按正态平移的 Mann–Whitney 功效近似，在 σ_g 的经验分布上取平均，Skin（75 vs 1,117）、Lung（126）、Lymphoid（94）在 β = −0.25/−0.5/−1.0 时 M1 功效都 ≈ 1.00，Myeloid（43）在 β = −0.25 时 ≈ 0.999。E3 只在"M1 功效介于 0.2 和 0.9"的格子里评估，所以很可能**一个合格格子都没有**；计划又没写此时 E3 算通过还是失败，决策规则就没有定义。同理，δ = −0.3 时血液靶 M1 的第一类错误接近 1，E1 不提供任何信息。
- **改法**：
  1. 把 β 和 δ 改成以 σ_g 为单位：β = c_β·σ_g，c_β ∈ {0, −0.1, −0.2, −0.35, −0.5}；δ = c_δ·σ_g，c_δ ∈ {0, −0.25, −0.5, −1}（具体数值冻结前定）。原来的绝对网格可以另外保留，只用于"整套优先级规则"层面的报告（那里 −0.5 和 −1 的绝对阈值才有意义）。
  2. 写明"功效"是指未校正单侧 α = 0.05 下的拒绝率（不是 BH 之后）。
  3. 写明：如果 Skin/Lung 没有满足 0.2–0.9 的格子，E3 算作 [失败 / 改在功效最接近 0.5 的格子评估]，二选一写死。

### M-3　偏态噪声的中心化规则自相矛盾（plan A §4 第 4 条小点）

- **问题**：原文是 "standardised to mean 0 (or median 0, Section 4 below)"。这句话本身就在第 4 节里，"Section 4 below"指向它自己，均值和中位数二选一也没有定下来。
- **理由**：k = 1 时中心化方式不影响零假设（各组噪声分布相同）；但 k = 1.5 时它决定哪个方法的"β = 0"才是真零假设。另外，秩检验（M1、M2、M4）的零假设既不是"均值相等"也不是"中位数相等"，而是 P(target < other) = 1/2（对应 HL 平移为 0）。尺度不同的偏态分布下，这三个条件互不相同，"null defined per method"按现有写法做不出来。
- **改法**：写死"均值为 0"（或"中位数为 0"）。k = 1.5 的偏态格子要么明确写成"只报告、不定义真值、不进入任何判据"，要么给出每个方法零假设的数值定义（M3：均值差 = 0；秩方法：用数值积分求出使 P(X<Y) = 1/2 的 β，把这个 β* 列入冻结材料）。

### M-4　Van Elteren 的连续性校正和方差没有写成公式，两个人会算出不同的 p 值（plan A §3 M2）

- **问题**："tie-corrected null variance, normal approximation with continuity correction"。
- **理由**：T = Σ W_s/(n_s+1) 的步长随层而变（每层 1/(n_s+1)，有结时减半），不存在通用的"0.5"。常见实现有三种：不校正、用 0.5、用 0.5/(n_s+1) 的某种组合。只有一个信息层时 M2 应该退化为 M1 的 Mann–Whitney（scipy 用的是 0.5 校正），这个一致性也需要写明。
- **改法**：写出公式，例如
  E[T] = Σ_s n_t,s / 2；
  Var[T] = Σ_s n_t,s·n_o,s / [12 (n_s+1)²] · [(n_s+1) − Σ_k (t_k³ − t_k) / (n_s (n_s − 1))]（结在层内计算）；
  p = Φ((T − E[T] + c)/√Var)，c = [明确数值，例如不做连续性校正，c = 0；或 c = 0.5·max_s 1/(n_s+1)]。
  再加一条验证：只有一个层时，代码结果必须与 `scipy.stats.mannwhitneyu(..., method="asymptotic")` 一致（若 c 的取法使二者不一致，就写明不要求一致）。冻结前在模拟数据上和 R 的 `coin::wilcox_test(... | stratum)` 或 `sanon` 对一次数值，并记录结果。

### M-5　基因组样混合模拟缺少决定结果的参数（plan A §4 "Genome-like mixture"）

缺少的参数有：
- 2% 非零基因的 β 取什么分布（固定值？从哪里抽？）；
- "a set of genes with β = 0 and δ < 0"占多少比例；
- δ 是对所有基因都按 OLS 系数分布抽取，还是只对这一组基因抽取（"most null"的基因 δ 是否为 0）；
- OLS 给出两个培养系数（Suspension、Other），而生成模型只有 δ·[suspension]，Other 层的效应取 0 还是也抽取；
- 混合模拟用哪种噪声、哪个 k；
- 重复几次（目前读起来只有 1 次；1 次的经验 FDR 方差很大）；
- 随机种子。

这些都会直接改变 M1/M2/M3 的经验 FDR，冻结后再定就等于冻结后选参数。**改法**：全部写成具体数值（例如 β ~ 从 {−0.5, −1, −1.5} 等概率抽取；culture-only 组占 5%；其余基因 δ = 0；Other 层效应 = 0；噪声 t5，k = 1；20 次重复；种子 20261119 + r）。

### M-6　μ_g 与 σ_g 独立抽样会破坏真实结构（plan A §4 第 1、2、5 条小点）

- **理由**（已计算）：每基因中位数与合并 SD 的 Spearman 相关系数为 **−0.64**（必需基因越负、SD 越大）。独立抽样会产生很多"μ_g < −1 但 SD 只有 0.1"的不现实基因，而"absolute effect < −1"这一步和 FDR 都取决于 μ 和 σ 的联合分布。
- **改法**：写成"从真实基因中有放回地成对抽取 (μ_g, σ_g)"。

### M-7　"FDR 的真值"定义有偏，对 M1 不公平，也没有考虑 δ（plan A §4 "A prioritised pair is a false positive if …"）

- **问题**：假阳性定义为"真 β > −0.5 或真 μ_g + β ≥ −1"。
- **理由**：(1) 这里的真值是"同培养方式内"的估计目标（M2/M3 的估计目标）。按定义，M1 的混杂信号会全部算作假阳性，所以这项比较必然对 M2/M3 有利，审稿人会说是循环论证。(2) 血液靶系大部分是悬浮系，它们真实的谱系中位数是 μ + β + δ，不是 μ + β；用 μ + β ≥ −1 判断"绝对效应"，会把真实绝对依赖很强的血液对判成假阳性，或者反过来。
- **改法**：写明"FDR 以同培养方式内估计目标为真值，按定义对未分层方法不利"；同时报告第二种真值：M1 的估计目标，即真实的谱系 vs 其余中位数差和真实谱系中位数（可以从生成模型直接算出）。绝对效应条件要明确用 μ + β（不含培养）还是真实谱系中位数（含 δ·悬浮比例），二选一。

### M-8　决策结果为 "Neither" 时，下游定义全部悬空（plan A §4 决策规则、§6；plan B §3）

- **问题**：plan A §6 定义"retained = prioritised by the recommended method"；plan B §3 用"plan A's recommended method"做分层与未分层比较。如果决策结果是"neither"，这两处都没有定义。在 M-1、M-2 不改的情况下，这个结果几乎必然出现。
- **改法**：写一条兜底规则，例如"若无推荐方法，§5 和 plan B §3 的比较一律用 M2，并标注 'not recommended by the simulation'"。

### M-9　plan B 中"分层方法的排名"没有定义（plan B §3 "Stratified vs unstratified"、"Exploratory"）

- **问题**：(1) "top 94 / top 376 / q < 0.05 block under plan A's recommended method"：M2 或 M3 下按什么排序？是 R1 的类比（q < 0.05 块内按分层 HL 或 OLS 系数排序，块外按 p 排序），还是别的？(2) M2 的检验族不是 467,091，而 plan B 的排名全集写死为 467,091。在 M2 下不可检验的对怎么排（排在最后？剔除？），没有写。(3) "top 94"是固定数字还是该方法自己优先级集合的大小，也没有写。
- **改法**：写成"对 Mx，按 R1 同样的结构排名：q_Mx < 0.05 的块按 Mx 的主效应量升序，其余按 p_Mx 升序；排名全集为 M1 与 Mx 都可检验的对；只在一侧可检验的阳性对照单独列出。top 94 指排名前 94，与 Mx 优先级集合大小无关"。

### M-10　plan B 内部矛盾：选择性标准里"1 个非本谱系细胞系"（plan B §1 第 4 条）

- **问题**：第 4 条要求"至少 2 个其他谱系细胞系"才合格，紧接着又写 "One non-lineage line only: grade B at best"，暗示只有 1 个也合格。
- **改法**：二选一写死。要么"只有 1 个 → 不合格"，要么"第 4 条：≥ 1 个；只有 1 个时最高评为 B 级"。

### M-11　plan B 内部矛盾：提示词和映射表的冻结时点（plan B 头部、§1 第 6 条、§2、§5）

- **问题**：头部说 "Search caps and prompts are last adjustable before freezing"（冻结指 v1），§2 说两个筛选者收到 "the same frozen prompt"，§1 第 6 条要求谱系映射表 "written before screening"；但 §5 把提示词、映射表、检索式都放进 **v2**，而 v2 要到筛选完成以后才存档。这样就没有时间证据证明它们在筛选前已经定下，也没有证据证明 OncotreeLineage 映射不是看了候选之后再调的。
- **改法**：把以下材料放进 v1：两个筛选者的完整提示词、26 个谱系各自的 `<cancer type terms>` 检索词、综述检索式、谱系映射表、随机复核用的种子。v2 只放筛选产物（日志、合格表、kappa）。

### M-12　模拟代码在运行前没有冻结（plan A §7 第 2–3 步）

- **问题**：决策规则完全取决于模拟结果，但模拟脚本是在 v1 之后编写、运行，到 v2 才和结果一起存档。区间类型、功效定义、种子、格子枚举等很多选择都可以在看到结果后调整，存档只能证明推荐结论早于真实数据结果，不能证明它没有在模拟上反复试过。
- **改法**：增加一步"v1b：模拟脚本 + 环境锁文件 + 种子，在运行前存档"；或者把 M-1 至 M-6 的所有细节都写进计划正文，使脚本没有自由度。推荐两者都做。

## 二、建议改

### S-1　E2r 处在边界上，结果会由与培养混杂无关的 Behrens–Fisher 问题决定（plan A §4 E2r）

按正态近似：靶组 SD 是其余组的 1.5 倍、且样本量很不平衡时（Skin 75 vs 1,117；Lung 126 vs 1,066；Myeloid 43 vs 1,149），Mann–Whitney 单侧 0.05 的实际水平约为 **0.08–0.084**；在悬浮层里 Lymphoid 83 vs 约 80，比较平衡，约为 0.052。M2 在贴壁层里同样很不平衡，所以 M2 的点估计大约在 0.08，再加上 MC 上界的 +0.012，基本就在 0.10 附近，通过与否几乎是抛硬币。HC3 OLS 对异方差更稳健，所以结果很可能是"因为 E2r，推荐 M3"。这本身不是错误，但应当：(a) 在计划里写下这个事先估算；(b) 说明 E2r 检验的是对尺度差异的稳健性，而不是对培养混杂的处理；(c) 考虑把 E2r 从决策规则里拿出来，只作为报告项；或者事先接受它可能决定选择。

### S-2　增加一个模型误设场景（plan A §4）

现有生成模型（各层之间加性的常数 δ，所有谱系平移相同）恰好就是 Van Elteren 和 M3 的假设，审稿人会说模拟对新方法有利。建议加一个场景：δ 随谱系不同（培养 × 谱系交互，例如对 Lung 的悬浮系减半），或者 Mixed 层取 δ/2。只报告，不进入决策。

### S-3　阳性对照主终点的推断方法（plan B §3 Primary endpoint、§4）

- 只有 8 个对照、可能只有 5–6 个不同基因时，按基因聚类的百分位 bootstrap 覆盖率明显不足。建议：(a) 主推断改用"按基因聚类的精确符号翻转（sign-flip）检验"，bootstrap CI 作为描述；或者 (b) 把"≥ 8 个对照"改成"≥ 8 个对照且其中 ≥ 8 个不同基因"。另外写明 bootstrap CI 的类型（percentile / BCa）。
- §4 说 15–30 对时"所有结果标为探索性"，§3 又说"CI 不含 0 才声称有差异"。需要写明 15–30 对时能不能写"有差异"（建议写成"探索性差异"）。
- §3 的"≥ 8 个才计算"应当与 §4 的"≥ 15 对且 ≥ 10 个基因"互相引用，避免读成两个独立条件。
- 写明 R1/R2 的"按 selectivity 排序"是升序（最负的排第一），并写明 selectivity 并列时取平均名次。

### S-4　阳性对照的裁定对 94 对不盲，这会直接影响主终点（plan B §0、§2）

作者知道哪些对在 94 对里，也就是 R2 顶部、也大多在 R1 块内的前列。作者在裁定边界候选时，哪怕是无意识的偏向，也会让 R1 相对 R0 显得更好。建议增加一个敏感性分析：只用两个 AI 筛选者**一致判为合格**的对、不经作者裁定，重算主终点。同时在局限性里明确写"裁定者不盲于 S2"。

### S-5　筛选者 1 的"隔离"需要技术手段（plan B §2）

"instructed not to look them up"只是指令。如果在本机运行，代理能读到桌面上的仓库和 S2。建议写明运行环境：无文件系统访问的云端会话，或不同机器/账户，并把这一点写进 Methods。

### S-6　M4 没有优先级规则和结果口径（plan A §3 M4、§5 第 3 条）

M4 只写了 BH，没有写报告哪些指标（q < 0.05？中位数差 < −0.5？绝对效应 < −1？）。另外"12 genes (24 pairs)"在 M4 下其实是 12 次检验（血液已合并），措辞要改。还建议说明 41 个非血液悬浮系里 Lung 占 16 个（已核对：Lung 16、Esophagus/Stomach 7、Bone/Breast/CNS 各 3、Eye/Head and Neck 各 2、其余各 1），所以对照组不均质。

### S-7　固定随机种子的具体数值（plan A §4、§5；plan B §2、§3）

"seeds fixed in the script"，而脚本写在 v1 之后。建议在计划正文写出种子数值，避免事后挑种子的质疑。

### S-8　M1 链条第 3 步需要补算 HL（plan A §3 M1）

"M1 (HL shift, restricted to the M2 test family, BH recomputed)"：族变小以后，可能有新的对变成 q < 0.05，它们不在 S9 的 9,805 对里，需要补算 HL。请写明补算，并且补算用与 `hodges_lehmann.py` 相同的精确方法。

### S-9　"bug fix 不算改计划"需要一个判别标准（plan A §4 末、§7）

建议写成"bug = 代码与本计划文字不一致；凡是计划文字没有规定、需要另作选择的情形，都算偏离（deviation），而不是 bug"。

### S-10　Section 0 的 OLS 数字用的是 4 水平培养变量，而 M3 用 3 水平（plan A §0、§3 M3）

`growth_confound.py` 用的是 Adherent/Suspension/Mixed/Unknown 共 4 水平（3 个哑变量），within-strata 置换（11.3/25）也用的是 4 个层。这些数字没错，但建议在 §0 注明"4-level GrowthPattern"，以免读者以为和 M2/M3 的 3 层一致。M3 的单侧 p 用 t 分布（自由度 n − p）还是正态，也应写明（现有脚本用的是 `use_t=True`）。

## 三、小问题

1. **plan A §2 "expected: Eye, Ampulla of Vater"**：模型层面核对，Eye 的信息层比例 = 7/10 = 0.70（会被标记）；Ampulla of Vater = 4/5 = **0.80**，不满足"below 0.80"。而且信息层里只有 4 个靶系，不到 5 个，所以 Ampulla 在 M2 下整体**不可检验**，根本不会进入"被标记"一类。建议改成"Eye 预计被标记（0.70）；Ampulla of Vater 预计不可检验（信息层内 4 个系）"。另外，"≥ 5 per stratum"敏感性分析下 Ampulla 为 0、Myeloid 为 39、Lymphoid 为 90。
2. **plan A §2 Other 层**：写明 `GrowthPattern` 缺失（NaN）也归入 Other。现有脚本先 `fillna("Unknown")`，计划文字没有说。
3. **plan A §2 文库**：在 26Q1 经过筛选的 2DS screens 里没有 "Humagne-CD"（只有 Avana 2,119、KY 902、TKOv3 7、Brunello 6 个 screen），保留不影响结果，但可以注明"Humagne-CD 在 26Q1 中未出现"。模型层面：Avana 822、Avana+KY 195、KY 116、unknown 53、"other" 6。"other" 的 6 个系在任何层里都达不到信息层标准。
4. **plan A §3 HL 的"恰好 50%"**：权重是 1/(n_s+1) 形式的有理数，浮点比较"恰好等于 50%"不可靠。建议用有理数运算（`fractions`），或以整数化权重（乘以 Π(n_s+1) 或其最小公倍数）判断。"the next"应写成"下一个**不同的**差值"。（推导本身我核对过：T(Δ) − E[T] = Σ_s [U_s(Δ) − n_t,s·n_o,s/2]/(n_s+1)，所以 T = E[T] 等价于"差值 > Δ 的加权比例 = 1/2"，加权中位数的说法正确；只有一个层时退化为普通 HL。）
5. **plan A §4 "E2 … in every cell with k = 1"**：写明是否包括共享血液场景的格子（建议不包括，那里的"零假设"取决于比较组里是否含另一个血液谱系）。
6. **plan A §4 E1**：E1 不进入决策规则。建议写明 E1 失败时怎么处理（例如"若 E1 失败，说明模拟没有再现混杂，如实报告并在讨论中说明"）。
7. **plan A §5 第 6 条**：无限制置换下要判断"校准"，需要先写好预期（例如"每次置换的优先级对数均值应 ≈ 0"）和失败时的处理。
8. **plan B §0 Garraway Table 2 的 7 对**：没有原文，**未核实**。冻结前请对照原文逐对核对，并把页码或表号写进计划。
9. **plan B §0 "recorded before freezing"**：写明是哪一次冻结（v1）。
10. **plan B §3 partial AUROC**：写明是对 R0/R1/R2 中的哪一个（或全部）计算，是否做 McClish 标准化。
11. **plan A §7 第 5 步与 plan B §5**：R0–R2 只需要现有的 `all_tests.csv`（不是 v3 输出），只有分层比较才需要 v3。措辞可以改成"R0–R2 用 v0 的 `all_tests.csv`（SHA 已在 v2 记录），分层比较用 v3 输出"。

## 五、审稿人可能抓的点（除上面各条以外）

1. **估计目标依赖设计**：Van Elteren 的有效权重 ∝ n_t,s·n_o,s/(n_s+1)，由靶谱系系数最多的层主导。对血液来说，主导的是悬浮层，而那里的比较组 75% 是另一个血液谱系，所以 M2 对血液的估计目标实际上接近"淋巴 vs 髓系"。计划已经用 M4 补充，但正文应把这一点写在主结果旁边，而不只放在方法里。
2. **GrowthPattern 本身是策展注释**：它可能受谱系影响（血液系默认标为悬浮），"Unknown"也和数据来源有关。计划已列为局限，建议再加一个"把 Unknown 当作缺失、剔除"的敏感性分析（§5 第 4 条已有"Mixed and Unknown excluded"，可以确认二者的定义一致）。
3. **谱系内亚型相关**：同一谱系内的系彼此不独立（亚型、来源病人），置换检验和模拟都假设可交换，这一点应当在局限性里写明。
4. **"新方法"的定位**：BMC Bioinformatics 要求方法学贡献。Van Elteren 加 BH 是标准组件，贡献主要在流程、模拟基准和比较。§6 已经避免说"first"，建议在引言里正面说明它与线性模型协变量方法（例如 DepMap 常用的线性模型/limma 式的谱系检验）的关系，最好在 M3 之外再加一个 limma 式的经验贝叶斯版本作为参照，至少讨论一下。
5. **模拟与真实数据的缺失值**：模拟是完整数据，真实数据有约 4% 缺失（cohort_stats：缺失比例 3.96%，1,444 个基因有缺失）。信息层的判定是按基因做的，模拟里没有这部分变异。可以说明，或者按真实缺失模式施加缺失。

## 六、结论

两份计划的统计主体是对的：Van Elteren 的形式、分层 HL 作为加权中位数的推导、BH 前缀性质、M1 → M2 的分解链条都没有发现错误；第 0 节可以核对的数字除 Ampulla 一处外都与仓库一致。但模拟部分有三处会让决策规则在设计上失效：E2 的 Monte Carlo 判据几乎必然失败（M-1）；效应网格太大，E3 无格可评（M-2）；"neither"时没有兜底（M-8）。另外还有几处冻结后才能确定的参数（M-3 至 M-6、M-9、M-12），以及 plan B 的两处内部矛盾（M-10、M-11）。

**结论：改完可以冻结**（"必须改"的 12 条全部修改并复核后才可冻结；按现稿冻结不可行）。
