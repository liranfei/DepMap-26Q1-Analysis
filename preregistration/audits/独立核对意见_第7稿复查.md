## 二、必须改

### X-1　c1 由"筛选者字段"和"脚本计算"两部分组成，组合方式没有写；三值逻辑下的 eligible 也没有写明（plan B §1 第 1 条和 "Judging rules"；提示词步骤 2 item 1）

- **问题**：
  - 提示词的 c1 只问"在目标癌种的癌细胞里**做了**功能缺失实验"。plan B 的 c1 是"做了**而且**降低了增殖（至少一个目标谱系的癌系 met）"。后一半要从 `target_lines_with_effect` 计算，前一半是筛选者的 c1 字段。两者怎么合成最终的 c1，没有写。
  - eligible 由 c1–c5 合成，各项都取三个值（met / not met / unclear），合成规则也只在提示词里写了一半（"eligible is met only if all met"），而现在 eligible 改由脚本计算，提示词里已经没有这句了。
  - in vivo 字段有第四个值"not done"，在 c3 的三值规则里算什么，也没有写。
- **改法**：在 plan B §1 的 "Judging rules" 里写成：
  1. 最终 c1 = 筛选者 c1 字段 AND"至少 1 个分配到目标谱系的癌系 met"（后一半按已写的计算规则得到三值结果）；
  2. 三值 AND：任一项 not met → not met；全部 met → met；否则 → unclear。eligible 用同一规则合成 c1–c5；
  3. in vivo 字段的"not done"按"not met"处理；
  4. 计算 c3、c4 时，同一个系在规范化后重复出现，只计一次（按匹配到的 ModelID 去重；匹配不上的系按规范化后的名称去重）。

### X-2　暂定谱系（合并时用）和最终谱系（步骤 2 后脚本算）可能不同，而且两名筛选者可能得到不同的目标谱系（README 规则 4 与"步骤间规则"第 3、4 条）

- **问题**：
  - "步骤间规则"第 3 条用步骤 1 两人所列细胞系的并集确定暂定谱系，这个谱系是合并键的一部分，构成步骤 2 的固定单位。
  - 谱系规则开头写的是"applied by script after step 2, to the cell lines the screeners listed"，规则 4 又用"matched target cancer lines"的多数来定目标谱系。按这个写法，步骤 2 之后每名筛选者各自的 `target_lines_with_effect` 都会重新算出一个目标谱系。
  - 结果有三种可能不确定的情况：两名筛选者对同一单位算出不同的目标谱系；最终谱系与合并键里的谱系不一致；同一论文的单位在步骤 2 后"变成"另一个谱系的对。这样 c3/c4 的判定、kappa 和阳性集合都会因此而变。
- **改法**（推荐）：
  1. **单位的目标谱系在合并时就固定**：按"步骤间规则"第 3 条的暂定谱系，冲突由作者核定。步骤 2 之后不再重新确定目标谱系。
  2. 规则 4 改成只用于"步骤间规则"第 3 条，也就是只在确定暂定谱系时使用。步骤 2 之后，脚本只给**每一个系**分配谱系，再按固定的目标谱系计算 c1/c3/c4。
  3. 写明步骤 2 输入清单的字段，例如 `unit_id`、批准的基因符号（附原文写法）、目标谱系、该谱系下原文的癌种（可以有多个）、来源 PMID/DOI。还要写明是否给出步骤 1 列出的细胞系。建议**不给**，免得筛选者照抄。提示词里"each unit is one gene, one target cancer type"要改成"one target lineage (with the cancer type(s) as written)"，与"同一论文、同一谱系的多种癌型合并为一个单位"一致。
  4. 提示词开头"Between the steps"一段把合并键写成"(Entrez ID, OncotreeLineage, source PMID)"，漏了"无 PMID 时用 DOI"。应与 README 一致。

## 三、建议改

- **X-3　列为目标系、但脚本分到别的谱系的系**（例如论文说是某癌，但 Model.csv 里属于另一谱系，或细胞系被错认）：按现在的规则，这类系既不计入 c3，也不进入 c4，c4 只看列在对照里的系。如果这个系在敲除后效应很强，它其实是不支持选择性的证据，却被直接丢掉了。建议写成："target-listed lines assigned to another lineage are treated as comparison lines; a target effect 'met' (reduced proliferation) counts as 'not met' for selectivity, otherwise 'unclear'"。反过来，列在对照里、却被分到目标谱系的系，现在的规则（不计入 c3 和 c4）是可以的。
- **X-4　裁定改的是什么**：eligible 现在由脚本计算，所以作者裁定和全文核查时应当**修改结构化字段**（c1、c2、c5 的值，以及每个系的效应），再由脚本重算，而不是直接改 c3、c4 或 eligible。请写明，并在 v2 里保留"裁定前 / 裁定后"两份字段表。全文核查 (b) 里的"no screener judged 'not met' on any criterion"，应写明这里的标准包括计算出来的 c3、c4。
- **X-5　敏感性分析 (a) 的定义**：eligible 改为计算以后，(a) 仍然可以定义，但要写清楚："a pair is included if at least one unit (same source paper) is computed 'eligible' from screener 1's fields **and** from screener 2's fields, using the fixed target lineage, without adjudication or full-text checks"。两名筛选者各凭不同论文判为合格的对，不算在 (a) 里。plan B §3 (a) 的"judged eligible"应相应改为"computed eligible from both screeners' fields for the same unit"。
- **X-6**：README 谱系规则 4 里"evidence in vivo only"那一句，在新规则下没有实际作用：没有细胞系的单位 c1 必然不满足。可以保留（用于确定暂定谱系），但建议注明"such units cannot meet criterion 1"，免得读者误以为只有 in vivo 证据也能合格。

1. **结构化字段能否支撑计算**：能。c3、c4 所需的系名、对照系的原文癌种和每个系的效应，加上 in vivo，信息都齐全。缺的是组合与去重规则（X-1），以及目标谱系的固定方式（X-2）。

3. **README 规则 4 与步骤间规则 3**：两者都用"目标系的多数谱系"，但作用的阶段和输入不同（步骤 1 两人的并集 vs 步骤 2 各自的清单），会产生不一致，见 X-2。
4. **敏感性分析 (a)**：仍然可以定义，按 X-5 写清楚即可。
5. **新矛盾**：除 X-1、X-2 和提示词开头漏了 DOI 那一处以外，没有发现别的。plan B §1、§2、§3 与 README 和提示词的其余部分彼此一致。

## 五、结论

第 6 稿的 8 条意见都已落实，步骤 2 的结构化设计可以支撑脚本计算。剩下两处会让结果因执行者而不同：c1 和 eligible 的三值组合规则没有写明（X-1）；目标谱系在合并时和步骤 2 后可能被确定两次（X-2）。这两处都只需要在 plan B §1 和 README 里补几句话，不涉及设计改动。
