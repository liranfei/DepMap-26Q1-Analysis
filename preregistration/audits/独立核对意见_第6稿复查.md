## 二、必须改

### W-1　c4 的"不同谱系"在提示词和 plan B 里仍是两种定义（`screener_prompt.md` 步骤 2 Criterion 4；plan B §1 第 4 条；README 谱系规则）

- **问题**：plan B 规定对照细胞系的谱系"用与靶系相同的规则判定"，也就是 README 规则，即 Model.csv 的 `OncotreeLineage`。提示词则让筛选者自己判断："lineage = organ or tissue system of origin … Cancer lines of another cancer type from the **same organ** do not count"。两者在以下情况下结论不同（都用 Model.csv 核对过）：
  - **食管 vs 胃**：在 Oncotree 里同属 Esophagus/Stomach，但是两个器官。按提示词，胃癌系可以作为食管癌的对照；按 plan B 不能。
  - **皮肤黑色素瘤 vs 葡萄膜黑色素瘤**：器官不同，组织系统相同（黑色素细胞）。按提示词，两种理解都说得通；按 plan B，二者是不同谱系（Skin / Eye）。
  - **肾横纹肌样瘤 vs 软组织横纹肌样瘤**：同一种肿瘤，在 Oncotree 里分属 Kidney / Soft Tissue。
  - **软组织 Ewing 肉瘤**：按器官属于软组织，在 Model.csv 里全部 28 个 Ewing 系都属于 Bone。
  - 结果是两名筛选者的 c4 判定与作者按 plan B 的判定会系统性地不同，敏感性分析 (a)"两名筛选者一致、不经裁定"的阳性集合也会和主集合用不同的标准。
- **(a) 改法（推荐）**：c4 里"谱系是否不同"这一半不再由筛选者判断。步骤 2 里，筛选者只对**每一个对照细胞系**记录两件事：名称，以及"无效应或效应 ≤ 一半"（met/not met/unclear）。然后由脚本按 README 规则给每个对照系分配谱系，再计算 c4 是否满足："不同谱系且满足效应条件的癌细胞系 ≥ 2 个"。提示词的输出要相应增加一个结构化字段，例如 `comparison_lines_with_effect`，每项写成"名称:met/not met/unclear"，项之间用分号分隔。这样 c4 的 kappa 就落在筛选者实际判断的那一半上。
- **(b) 备选**：在步骤 2 的输入里为每个单位附上 Model.csv 的谱系表（只有注释），并在提示词里写明"lineage = the OncotreeLineage given in the attached table"。
- **(c) 两种做法都要补的规则**：Model.csv 共有 2,154 个模型，其中 **151 个是 Non-Cancerous**（Fibroblast 45、Lymphoid 32、Normal 13、Prostate 7、Eye 7、Lung 6、CNS/Brain 6、Muscle 5 等）。按 README 规则 1，这些非癌模型也会被分配到一个谱系。需要在 README 里加一句："a line whose matched model has `OncotreePrimaryDisease` = 'Non-Cancerous' is a non-cancer line: it does not count as a target or comparison cancer line"。

### W-2　只读到摘要时，"未报告 → not met"会系统性地排除付费墙后的论文（提示词步骤 2 的 Rules；plan B §1、§2）

- **问题**：c2 至 c4（试剂数、细胞系数、对照系）在摘要里几乎从来不写。如果筛选者只能读到摘要，按"Information not reported → not met"，这类单位一律"不合格"。而 plan B 只要求作者打开**进入主集合**的论文全文，以及因来源或选择性被排除的那部分。因 c2/c3 不满足而被排除的单位永远不会被复核。
- **后果**：主集合会偏向开放获取的论文，偏向的程度又取决于两名筛选者各自的全文获取能力：筛选者 1 在隔离环境里，筛选者 2 由作者运行，两人能读到的全文很可能不同。这样一来，kappa 混入了"能不能读到全文"的差别，结果也随执行环境改变。
- **改法**：
  1. 提示词和 plan B 都写明："if only the abstract is available, criteria not addressed in the abstract are 'unclear' (not assessable), not 'not met'"。plan B §1 的"not reported in the paper"本来指的是论文全文，这样写和它一致。
  2. plan B §2 加一条：任何一名筛选者标为"abstract only"、且没有任何一条明确判为"not met"的单位，都由作者读全文判定。读不到全文的，记为"not assessable"，并报告这类单位的数量。
  3. 报告两名筛选者各自"abstract only"单位的比例。

### W-3　c5 的排除范围：提示词写"genome-scale or other large-scale screen"，plan B 写"genome-scale screen"（提示词步骤 2 Criterion 5；plan B §1 第 5 条）

- **问题**："other large-scale"会把来自几百个基因的聚焦文库筛选（例如激酶组、表观组文库）的基因也排除掉，plan B 不排除这些基因。这是我上次漏看的一处不一致。
- **改法**：两处统一，并给出可操作的界限。例如两处都写"genome-scale (≥ 1,000 genes targeted) loss-of-function screen"；或者两处都写"genome-scale or focused library screen of ≥ 100 genes"。前一种与 plan B 现有的意思一致。

### W-4　两步之间的合并规则还缺两条（`screener_prompt.md` "Between the steps"；README；plan B §2）

1. **合并键**：要写明并集里的单位按什么去重。建议用（Entrez ID，OncotreeLineage，来源论文）作键，来源论文先统一为 PMID：DOI 一律经 PubMed/Crossref 转成 PMID，转不了的才保留 DOI。还要写明：同一篇论文里同一基因、同一谱系的几种癌型，合并成一个单位。
2. **用哪个细胞系清单分配谱系**：README 规则 1 用的是"论文点名的细胞系"，但步骤 1 是两名筛选者各列一份 `target_cell_lines`，两份可能不同。建议写成"取两名筛选者所列细胞系的并集；两者冲突时，作者读原文核定并记录理由"。
3. （建议，不强制）plan B §1 第 6 条的 PMID/DOI 程序化核验目前放在"adjudication 之前"，建议提前到**步骤 2 之前**，先剔除编造或错配的来源（剔除的记录也列入 v2）。这样做可以避免两名筛选者花时间判定不存在的论文，也不会让 kappa 受此影响。

## 三、映射表与谱系规则的核对

- **新增的行都与 Model.csv 一致**：尿道癌 → Bladder/Urinary Tract（2 个系）；骨巨细胞瘤 → Bone（1）；混合表型/系别不明的急性白血病 → Myeloid（1）；卵巢生殖细胞肿瘤 → Ovary/Fallopian Tube（1）；妊娠滋养细胞疾病 → Uterus（3）；子宫平滑肌肉瘤/子宫肉瘤 → Uterus（3）；HCC 合并胆管癌 → Liver（1）；软组织 Ewing → Bone（全部 28 个 Ewing 系都在 Bone）；肾 / 肾外横纹肌样瘤 → Kidney / Soft Tissue（各 5）；小细胞肺癌和肺神经内分泌肿瘤 → Lung（26）。
- **合理的选择**：黏膜黑色素瘤标为 not mapped（Model.csv 把外阴/阴道黏膜黑色素瘤放在 Vulva/Vagina，而该谱系只有 2 个系）；部位未注明的黑色素瘤 → Skin；类型未注明的淋巴瘤 → Lymphoid；部位未注明的间皮瘤 → Pleura；部位未注明的横纹肌样瘤标为 not mapped。这些都是合理的事先选择。
- **细胞系匹配键**：在 Model.csv 的 2,154 个模型里，规范化后的 `StrippedCellLineName` 全部唯一（0 个重复）。`CellLineName` 有 3 个键、`CCLEName` 前缀有 15 个键对应到不同谱系的多个模型，README 已规定这类情况记为"unmatched"，规则完整。由于大多数名字在第一级就能唯一匹配，后两级只起补充作用。
- **剩下的小问题**：
  - 癌种原文与映射表行的对应是人工文本匹配。建议写明"由作者完成，有疑义的记录理由"。
  - 精原细胞瘤和性腺外生殖细胞肿瘤不在表中，按规则 3 会成为 unclear。这可以接受，也可以显式加一行 not mapped。
  - 规则 1 只写了"全部未匹配 → 转规则 2"，没写部分匹配的情况。建议补一句"部分匹配时，只用已匹配的系"。
- **c4 的谱系判定**见 W-1。

## 四、检索同义词

新增的词（Q07 oligodendroglioma / ependymoma / embryonal tumo(u)r，Q08 cervical squamous / adenocarcinoma，Q09 esophagogastric / GEJ，Q11 nasopharyngeal，Q13 hepatoma，Q16 myelogenous / MPNs / myelodysplastic，Q26 endometrial adenocarcinoma）语法都正确，补的都是上次指出的遗漏。计数变化是 Q07 57→59、Q11 17→20、Q13 43→44、Q16 85→95，其余不变，幅度合理。有两点需要知道：
- Q07 的"embryonal tumor"也会命中颅外的胚胎性肿瘤。映射这一步会把它们纠正过来，影响只是增加一点筛选工作量。
- Q16 现在是 95 条，Q15 是 100 条。正式检索那天两者都可能超过 100，"Best Match 前 100"的截断主要影响这两个血液谱系。现在已经规定保存全部 PMID，可以事后评估截断的影响。建议在结果里单独说明这一点。

## 五、建议改

- **W-5　kappa 的报告方式**：大多数单位会"不合格"，阳性比例很低，kappa 会被压得很低（kappa 悖论）。建议同时报告每条标准的阳性比例，以及 PABAK 或 Gwet's AC1；三分类（met / not met / unclear）的 kappa 用无权重的。
- **W-6　敏感性分析 (f) 在对层面的规则**：一个对有多篇合格论文，只有其中一篇被标记时，是只剔除这篇论文、该对仍可凭其他合格论文保留，还是整对剔除？建议写成"去掉被标记的论文后，按'至少一篇论文单独满足'重新判定"。
- **W-7　机构清单**：
  - `match_terms` 里有多个词时用"; "分隔，README 应写明分隔符，并写明匹配不区分大小写。
  - 用窄词（例如"Donnelly Centre"而不是"University of Toronto"）是合理的取舍。但"Broad Institute"、"Dana-Farber"、"Princess Margaret"、"Novartis"都是很大的机构，会标记大量与筛选项目无关的组。好在它们只用于敏感性分析，标得宽一些是偏保守的方向。建议在 README 里写明这一点。
  - 可以考虑补上 Project Score 后来的合作单位"Open Targets"和"Human Technopole"。补不补都可以，但要在冻结前定下来。
- **W-8　来源类别"unclear"与 c5"met"的关系**：plan B 写"eligible papers all of origin 'unclear' → excluded from primary set"。按现在的定义，c5 met 意味着已经确定来源不是筛选，这时 origin category 的"unclear"只能表示"不是筛选，但无法归入其余类别"。建议在 plan B 和提示词里各写一句，说明它的含义，避免有人把它理解成"不知道是否来自筛选"（那种情况 c5 本应判 unclear）。
