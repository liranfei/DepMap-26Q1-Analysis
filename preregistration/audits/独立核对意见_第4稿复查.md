## 二、新写进去的公式和数字的核对

1. **Var[T]、E[T]、c（plan A §3 M2）**
   - E[T] = Σ n_t,s/2 正确：E[W_s] = n_t,s(n_s+1)/2，除以 (n_s+1) 即得。
   - Var[T] 是标准的带结方差 Var[W_s]/(n_s+1)² 逐层相加，正确。
   - 单层时，scipy 的 alternative = "less" 计算的是 p = Φ((U₁ − n_t n_o/2 + 0.5)/σ_U)。这里 U₁ = W − n_t(n_t+1)/2，所以 U₁ − n_t n_o/2 = W − E[W]。换算到 T 的尺度，连续性校正就是 0.5/(n+1)，与 c = 0.5·max_s 1/(n_s+1) 在单层时完全相同。
   - **数值核对**：2,000 组随机样本，n_t、n_o 取 3–59，数据取一位小数制造结。按计划公式算的 p 与 `scipy.stats.mannwhitneyu(..., alternative="less", method="asymptotic")` 的最大绝对差为 1.4×10⁻¹⁵。所以等价成立。
   - **多层时**：c 取最大的格点步长（来自最小的信息层）的一半，比"最小步长的一半"更保守，方向上是对的。主分析的三层分别约有 923、163、106 个系，c ≤ 0.5/107，影响可以忽略。在"培养 × 文库"敏感性分析里，最小信息层可以只有 6 个系（c = 0.5/7）。如果某个小谱系（例如 Prostate，贴壁 5 个系）的 √Var[T] 约为 0.64，c 大约是 0.11 个 SD，会略偏保守。这不是错误，建议在敏感性分析结果旁边注一句。
2. **加权中位数用整数权重 L/(n_s+1)**（L 为最小公倍数）：正确，可以精确判断"恰好一半"。
3. **M3 的自由度 n − 4**：截距、靶谱系、2 个培养哑变量，共 4 个参数，正确。
4. **种子**：模拟格子 20261119 + i，i 最多几百；混合模拟 30261119 + r，r 为 0–19；置换 42 + b，b 为 0–999。三者互不重叠，正确（与 `genome_perm.py` 的 `default_rng(42 + b)` 一致）。**但** plan B 的种子 20261120、20261121、20261122 落在模拟格子的种子范围内（对应 i = 1、2、3），与"范围不重叠"的说法不符。用途不同，统计上不会造成问题，只是说法不准确，见小问题 1。
5. **软件版本**：本机 Python 3.13.12，numpy 2.4.4、pandas 2.3.3、scipy 1.17.1、statsmodels 0.14.6，与计划 §7 和仓库 `requirements.txt` 一致。建议在 v1 里也写明 Python 3.13.12。
6. **第 0 节新数字**：
   - 合并谱系内 SD 中位数 0.133，5%–95% 为 0.102–0.334；与中位数的 Spearman 相关 −0.64。与我上次的计算一致。
   - 41 个非血液悬浮系的构成：16 + 7 + 3×3 + 2×2 + 5×1 = 41，与 Model.csv 一致。
   - 无限制置换的均值 0.0、最大 0：与 `permutation_summary_genome.json` 一致。
   - 文库水平计数 822/116/195/6/53（合计 1,192）、Suspension × KY 有 7 个系、Ampulla 信息层里有 4 个系：都一致。
   - **§1 的"约 75%"不对**，见 N-2。

## 三、新发现的问题

### 必须改

**N-1　E3 拿 M3 和 M1 比，按已知的渐近相对效率，M3 几乎必然不通过；决策规则因此实际上总是落到 M2（plan A §4.5 E3、§4.6）**

- **问题**：E3 要求 M3 在 k = 1 的格子里，功效 ≥ 0.9 × M1 的功效。M1 是秩检验，M3 是 OLS/t 检验，两者的效率比由噪声分布决定，与培养混杂无关。
- **理由**（解析计算）：Wilcoxon 相对 t 检验的渐近相对效率（ARE），在 t₅ 噪声下约为 1.24；在 sdlog = 0.5 的对数正态噪声下约为 1.58（ARE = 12σ²(∫f²)²，其中 ∫f² = e^{s²/4}/(2s√π) ≈ 0.601，σ² ≈ 0.365）。
  - 在 M1 功效约 0.5 的格子里（正好是 E3 的兜底格），M3 的功效：t₅ 下约 Φ(1.645/√1.24 − 1.645) ≈ 0.43，偏态噪声下约 0.37，都低于门槛 0.45。
  - 另外，噪声长尾向负、做"更低"单侧检验时，学生化 t 统计量会偏保守（Edgeworth 近似：Myeloid 约 43 个系时，实际水平约 0.02–0.03），M3 的功效还会更低。
  - 结果：M3 基本不可能满足 E3。M2 满足就推荐 M2；M2 不满足，M3 也不满足，于是"neither"，兜底仍然用 M2。不管模拟结果如何，实际使用的方法都是 M2，模拟只能决定 M2 是否带"not recommended"标注。审稿人会认为这个决策规则是预先定好结果的。
- **改法**（二选一，推荐 a）：
  (a) E3 改成和**各自的未调整版本**比较：M2 对 M1（同为秩检验），M3 对"不加培养协变量的 OLS（HC3）"。这样 E3 衡量的是"调整本身造成的功效损失"，与秩检验和 t 检验的效率差无关。
  (b) 保留现在的写法，但在 §4.5 写明事先已知的结论："由于 ARE，M3 预计不满足 E3，因此决策实际上只检验 M2 是否满足 E2 和 E3"，并删掉"M3 is recommended"这一分支，免得名不副实。
- 另外请写明 E3 要求**每一个**合格格子都满足（现在的文字可以读成任意一格）。

**N-2　plan A §1 "about 75% of the comparators are the other blood lineage"与数据不符（这个数字源自我上次意见第五节第 1 条的错误，在此更正）**

- **核对**：悬浮层共 163 个系。Lymphoid 的比较组 = 163 − 83 = 80 个，其中 Myeloid 39 个，占 **49%**；Myeloid 的比较组 = 124 个，其中 Lymphoid 83 个，占 **67%**。"75%"（122/163）是血液系在**整个悬浮层**里的占比，也就是对**非血液**谱系而言，比较组的大约 75% 是血液系。
- **改法**：改成"in the suspension stratum the other blood lineage makes up about half (lymphoid: 39 of 80) to two thirds (myeloid: 83 of 124) of the comparators, so the M2 estimand for blood lineages is partly a lymphoid-vs-myeloid contrast"。"close to lymphoid vs myeloid"说过头了，建议删掉。"权重由悬浮层主导"这一点本身是对的：Lymphoid 悬浮层的权重 83·80/164 ≈ 40.5，贴壁层约 4.0，其他层约 6.5，悬浮层约占 79%。

### 建议改

**N-3　T2 真值的计算方式还有两种读法（plan A §4.4 T2）**

"including δ times the lineage's suspension fraction"有两个问题：(1) 两个分布混合后，中位数之差不等于 δ × 比例（那是均值之差）；(2) 没有说明比较组"其余系"的悬浮比例也要计入（对非血液谱系，其余系里有约 122 个血液悬浮系）。**改法**：二选一写死。(a) 用均值定义：true lineage-vs-rest difference = β + δ·(f_target − f_rest)，target level = μ_g + β + δ·f_target，其中 f 是悬浮比例；(b) 用总体中位数定义：按生成模型数值求混合分布的中位数（写明求解方法）。推荐 (a)，简单，也能精确复现。

**N-4　R1(Mx) 与 R1 的比较要在同一个排名全集里（plan B §3）**

R1(Mx) 的全集是"M1 与 Mx 都可检验"的对，但对照的 R1 用的是 467,091 的全集。top 94 / top 376 的位置受全集大小影响，块内名次则不受影响。**改法**：写明"做分层与未分层比较时，R1 也在同一个共同全集里重新排名（q 值仍用原来的 M1 值）"。

**N-5　sign-flip 的统计量要与点估计一致（plan B §3 Primary endpoint）**

点估计是"对照层面的平均差"，而翻转的是"每个基因的平均 d"。如果一个基因有多个对照，按基因平均和按对照平均的权重不同。**改法**：写成"统计量 D = (1/N) Σ_g Σ_{i∈g} d_i；每次翻转把基因 g 的所有 d_i 一起变号"，或者统一改为"基因均值的平均"。点估计、检验和 bootstrap 必须用同一个定义。

**N-6　mixture 里 δ 的来源要写清楚是哪一个 OLS（plan A §4.4）**

写明这个 OLS 用 3 水平培养变量、绝对单位、谱系固定效应，并写明在哪一步计算（建议在 v1b 之后、模拟之前，脚本属于 v1b）。

### 小问题

1. plan B 的种子 20261120–20261122 与 plan A 的格子种子范围重叠（第二节第 4 条）。建议改成例如 40261120–40261122，使"种子范围互不重叠"的说法在两份计划里都成立。
2. plan A §4.3 的"约 0.08 / 约 0.05"：Lymphoid 约 0.05 只适用于 **M2**（悬浮层里 83 比 80，比较平衡）；**M1** 下 Lymphoid（94 比 1,098）也约为 0.08。建议写成"M1：四个谱系约 0.08；M2：Lymphoid 约 0.05，其余约 0.08（正态近似）"。
3. plan A §3 M2 的"exact permutation p values on small simulated examples"：写明是**层内**精确置换，以及可接受的差异（例如在 c 的作用之外，|Δp| < 0.01 或比例差 < 10%）。
